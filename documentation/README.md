# TITAN Documentation

This collection of files serve to generally document different TITAN subsystems and operations.

**These should not be treated as the exhaustive documentation of TITAN**, many parts have local `README.md` files which will explain them in greater detail than makes sense to include here. For example the [`firmware/README.md`](../firmware/README.md) covers how to upload code to the microcontrollers, just like [`vision/README.md`](../vision/README.md) covers how updates should be made to the RPi's code.
